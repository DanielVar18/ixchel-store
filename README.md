# IXCHEL Store

Sitio de la tienda IXCHEL: familia Go, planes de MediGO y NurseGO, catálogo de formatos, complementos, documentos legales y flujo de compra en modo demostración.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub (por ejemplo `ixchel-store`).
2. Sube esta carpeta a la rama `main`.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment** elige **Deploy from a branch**.
5. Branch: `main`, carpeta: `/ (root)` y guarda.

La página queda en `https://TU-USUARIO.github.io/ixchel-store/`.

El archivo `.nojekyll` evita que GitHub Pages ignore carpetas de assets.

## Contenido

- `index.html` — página
- `css/styles.css` — estilos
- `js/store.js` — tienda, cuenta y bolsa (solo en el navegador, no se guarda)
- `assets/` — logotipos y pantallas

Precios, cuentas, pagos y descargas son una demostración: no hay servidor ni cobro real.
